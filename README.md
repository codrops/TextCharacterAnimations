# Text Character Animations with GSAP

Nineteen character by character text animations on one page, each playing as it scrolls into view, four of them drawn in WebGL.

![Text Character Animations with GSAP](https://tympanus.net/Demos/TextCharacterAnimations/og-image.jpg)

[Article on Codrops](#)

[Demo](https://tympanus.net/Demos/TextCharacterAnimations/)

## Installation

Run this demo on a [local server](https://developer.mozilla.org/en-US/docs/Learn/Common_questions/Tools_and_setup/set_up_a_local_testing_server).
